Privacy Policy – GProduction Shorts Uploader

Last updated: 8 November 2026

GProduction Shorts Uploader ("the App") is a private desktop script run by G Production, the owner of the YouTube channel @giproduction-music. It uploads short vertical clips (YouTube Shorts), cut from G Production's own music videos, to that channel only. The App has a single user: the channel owner.

YouTube API Services

The App uses YouTube API Services. By using the App you agree to be bound by the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

What data the App accesses

The App requests only the youtube.upload permission. It uses it to upload video files and their title, description and tags, which are written by the channel owner and stored on the owner's own computer. The App does not read, collect or store any other YouTube data, comments, analytics or information about other users.

How data is stored

The OAuth access token is stored only on the channel owner's computer, in a local file readable only by that user. After each upload the App stores the resulting video ID and date in a local log file on the same computer. No data is sent to any server other than Google's, and no data is shared with or sold to third parties.

How to revoke access and delete data

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Deleting the App's local folder removes the stored token and log. Data stored on the computer is deleted within 7 days of revocation.
